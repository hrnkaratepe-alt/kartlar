# kartlar

Telefonda çalışan İngilizce öğrenme kartları. `index.html` dosyasını tarayıcıda açman yeterli.

- 72 kelime ve cümle kartı: Günlük, Yemek, İş, Seyahat, Duygular, Yazılım
- Türkçe harflerle okunuş, sesli dinleme (normal / yavaş), örnek cümleler
- Günde 20 kartlık hedef ve 🔥 seri sayacı
- Bilmediğin kartları daha sık gösteren tekrar sistemi (Leitner kutuları)
- İlerleme telefonun tarayıcısında saklanır
